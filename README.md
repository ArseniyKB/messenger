# 🚀 PyTelegram Messenger

A real-time messaging app inspired by **Telegram**.

## ✨ New Features Added
- ✅ **User Login / Registration**
- ✅ **Multiple Chat Rooms**
- ✅ **Beautiful CustomTkinter Desktop Client**
- Real-time messaging
- Docker & CI/CD

## Quick Start

1. `pip install -r requirements.txt`
2. `python run.py` (Web server)
3. Open http://localhost:5000 or `python desktop_client.py`

**Note:** Full login/rooms integration in progress - current version has foundation.
